
🧮 Advanced Math Calculator – Future Roadmap

This project started as a Gaussian Elimination Calculator, and the plan is to gradually expand it into a full-featured mathematical calculator capable of solving complex systems and performing advanced operations.


---

✔️ Current Features

Input any square system of equations (n×n)

Step-by-step Gaussian elimination

Displays the upper triangular matrix after each elimination

Handles pivoting and row swapping



---

✅ Planned Features / Milestones

Milestone	Feature	Description

v1.1	Back Substitution	Solve for the variables  after elimination

v1.2	Partial Pivoting & Scaling	Improve numerical stability for large systems

v1.3	Gauss-Jordan Elimination	Reduce matrix to reduced row echelon form

v1.4	Support for Non-square Systems	Handle underdetermined or overdetermined systems

v1.5	LU Decomposition	Factor matrices into L and U to solve multiple systems efficiently

v1.6	Determinant & Inverse Calculator	Compute determinants and inverse matrices

v1.7	Step History & Undo	Store all matrix states to allow reviewing or undoing steps

v1.8	GUI / Interactive UI	Build a desktop GUI using JavaFX or Swing

v1.9	Advanced Math Functions	Integrate polynomials, matrix operations, and eigenvalues

v2.0	Full “Complex Math Calculator”	Combine all features into a comprehensive solver



---

✔️ Notes

Each milestone will include testing and step-by-step outputs for clarity

Focus is on modular OOP design so new features are easily added

The project aims to be educational, extensible, and user-friendly
